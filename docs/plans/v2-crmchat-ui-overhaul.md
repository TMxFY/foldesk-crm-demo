# v2 — Редизайн интерфейса Foldesk 1:1 под эталон CRMChat (Desktop App + Landing)

## Цель
Превратить текущий черновой интерфейс (`app/templates/index.html`, `app/static/app.css`, `app/static/app.js`, `app/templates/landing.html`) в полноценный, неотличимый по уровню исполнения и архитектуре от оригинала (`crmchat.ai`) десктопный продукт с левым сайдбаром воркспейса, тулбаром фильтрации, эталонной Kanban-воронкой (с цветными аватарами, превью следующего шага/даты, pill-бейджами суммы/папки и счётчиками), 3-панельным Unified Inbox + Messenger + Lead Drawer и демо-сидингом для живого просмотра, сохранив **100% прохождение `./scripts/verify.sh` и всех e2e Playwright-тестов** (включая `axe-core` WCAG AA и `contrast.py`).

## Ключевые архитектурные решения

1. **Левый App Sidebar (`232px`, `aside.sidebar`) — точная структура CRMChat**:
   - Шапка воркспейса: логотип-монограмма Foldesk + `h1.brand` (`Foldesk`) + подпись воркспейса (`My workspace · Team`) со стрелкой переключателя.
   - Навигация `nav.nav` с SVG-иконками Lucide (`16px`, stroke `1.5`), сгруппированная по разделам (`CRM`, `Мессенджер`, `Интеграции`):
     - `Воронка` (`#s07`), `Лиды` (`#leads`), `Карточка` (`#s09`), `Папки` (`#s11`)
     - `Входящие` (`#s04`), `Переписка` (`#s05`), `У чата` (`#s06`), `Напоминания` (`#digest`), `Аккаунт` (`#accounts`)
   - Переключатель режима отображения (`Все панели` / фокус на выбранном разделе по клику с плавным скроллом, без `display: none` на секциях по умолчанию, чтобы Playwright `toBeVisible()` в `F01–F17` проходил мгновенно без дополнительных кликов).
   - Нижний блок сайдбара: кнопка `Демо-данные` (`POST /api/demo/seed` — наполняет реалистичными сделками, перепиской, папками и напоминаниями в 1 клик, не затрагивая пустую базу в автотестах) и переключатель темы (`#theme` «Тема»).

2. **Верхний Workspace Header & Filter Bar (как в `crmchat_pipeline_crop.png`)**:
   - Слева: дропдаун вида `[ ▤ Pipeline ⌄ ]`, компактный поиск (`#search` с переключателем `В CRM` / `В Telegram`, полем `#q` и кнопкой `Найти`), статус live-сокета (`#inbox-live` с индикатором).
   - Справа: статус подключённого Telegram-аккаунта, кнопка быстрой сводки и быстрый переход к добавлению лида.

3. **Эталонный Kanban Pipeline (`#s07`)**:
   - Компактный горизонтальный тулбар фильтрации в одну строку (`Стадия`, `Папка`, `Виды`, `Имя вида`, `Сохранить вид`, `Сбросить`).
   - 5 колонок (`Лид`, `Разговор`, `Ждём`, `Выигран`, `Проигран`) на подложке `var(--sunken)` с шапкой: цветной индикатор стадии + название (`h3`) + счётчик карточек + суммарный объём колонки.
   - Карточки `a.card` в точном формате CRMChat:
     - Слева: круглый аватар `36px` с инициалами (`aria-hidden="true"`).
     - По центру: жирное имя `14px/600`, строка даты/следующего шага (`Сегодня · ...` или `@username · ...`), снизу pill-бейдж (`@username` / папка / статус) в акцентной плашке.
     - Справа: круглый бейдж активности/непрочитанных.

4. **3-панельный Unified Inbox + Chat + Lead Inspector (`#s04` + `#s05` + `#s06` + `#s09`)**:
   - Единый 3-колоночный фрейм мессенджера (`320px | minmax(380px, 1fr) | 380px`):
     - Левая панель (`#s04` Входящие): поиск, фильтр-чипы (`Ждёт ответа`, `Непрочитанные`, `Группы`, `Без звука`), плотный список диалогов с аватарами, превью и бейджами `.count`.
     - Центральная панель (`#s05` Переписка): шапка активного чата (`#thread-head` с аватаром, именем, `@username`, плашкой `С аккаунта ...`), скроллящаяся лента сообщений (`ol#messages` с бабблами `in`/`out`), нижний компактный composer (`#reply-form` с `textarea#reply-text` в 1 строку + кнопки `Отправить` и `Непрочитанное`).
     - Правая панель (`#s06` Рядом с чатом + `#s09` Карточка): контекстная панель сделки прямо у чата с табами/блоками свойств, чеклистом задач, кастомными полями и таймлайном заметок/напоминаний.

5. **Компактные панели Напоминаний (`#digest`), Аккаунтов (`#accounts`), Папок (`#s11`) и Списка лидов (`#leads`)**:
   - `#digest`: карточки напоминаний с цветовой индикацией (`Просрочено` / `Сегодня` / `Дальше`), быстрыми кнопками `Сделано`, `Отложить`, `К лиду` и отправкой утренней сводки в бота (`#digest-send`).
   - `#accounts` + `#s11`: карточки аккаунтов со статусами (`на связи`, `активен`) в стиле Telegram Accounts из CRMChat, компактная форма подключения по телефону/коду/2FA и список синхронизации папок Telegram.
   - `#leads`: компактная горизонтальная панель быстрого создания карточки (`#manual-lead`) и чистая таблица сделок (`table` с `#lead-rows`).

6. **Демо-сидинг (`POST /api/demo/seed` в `app/main.py`)**:
   - Идемпотентный маршрут `/api/demo/seed`, который заполняет локальную базу реалистичными лидами, папками (`Web3 Founders`, `VIP Партнёры`, `Входящие заявки`), историей сообщений в личных диалогах, заметками, задачами, кастомными полями (`Сумма сделки`, `Компания`) и напоминаниями.
   - Вызывается кнопкой «Загрузить демо» в интерфейсе (и нами для живого показа в браузере), но **не вызывается при `/api/test/reset`**, чтобы все автотесты работали на чистой БД.

## Затрагиваемые файлы и функции
- `app/main.py` — маршрут `POST /api/demo/seed` (`seed_demo_data`).
- `app/templates/index.html` — новая 1:1 структура App Shell, Top Filter Bar, Kanban Workspace, 3-Pane Inbox + Chat + Lead Drawer, Digest & Accounts Grid, Leads Data Table.
- `app/static/app.css` — полная переработка стилей на базе CSS-токенов (`replica/design/tokens.css`), без запрещённых hex-цветов, с идеальным контрастом WCAG AA для `axe-core` и `contrast.py`.
- `app/static/app.js` — обогащение рендера карточек Kanban (`renderBoard`), списка чатов (`renderDialogs`), шапки и бабблов чата (`renderThread`), карточки лида (`paintCard`), плюс обработчик `#seed-demo` и переключения фокуса разделов.
- `app/templates/landing.html` + `app/static/landing-desk.png` — обновление скриншота рабочего стола на лендинге после пересборки UI.
